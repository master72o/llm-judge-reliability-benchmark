# Judge Benchmark Figures Directory

This directory stores visual analytics generated by the judge reliability benchmark suite:

- `prompt_ablation_comparison.png`: Bar chart comparing Pearson $r$, Spearman $\rho$, and Agreement Rate across Baseline (Prompt A), Detailed Rubric (Prompt B), and Chain-of-Thought (Prompt C).
- `bias_analysis.png`: Grouped bar chart showing Verbosity Bias (Pearson $r$) and Formatting Boost Delta ($\Delta$) by prompt strategy.
- `judge_confusion_matrix.png`: Heatmap confusion matrix of Baseline Judge vs Human Ground Truth.
